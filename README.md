# A2Z Edit — Acquisition Microsite

A polished, responsive, mock-data-driven acquisition brief for **A2Z Edit (a2zedit.com)**, built and documented by **Afaq Ahmad**.

## What is built

- Responsive shared navigation, footer, active route styling, and mobile menu.
- Landing page with product positioning, traction snapshot, trust signals, and acquisition CTA.
- `/overview` — business overview, included product surface, and monetization paths.
- `/metrics` — mock SEO and traffic dashboard with an illustrative trend visual.
- `/features` — categorized catalog of image, PDF, OCR, and utility tools.
- `/deal-room` — pricing, included assets, transfer checklist, and client-side inquiry form.
- `/faq` — expandable buyer-focused questions and answers.
- Custom A2Z Edit favicon, metadata, theme tokens, responsive layout, keyboard-visible focus states, and semantic page structure.

## Mock data status

All acquisition figures and analytics shown in this build are presentation mock data based on the seller-provided brief. The inquiry form simulates a successful submission in the browser and does not send or store information.
